# Personal Responsive Webpage

## About the Project
This project is a personal webpage created using HTML, CSS, and Bootstrap 5. It demonstrates a responsive layout with different sections and a clean user interface.

## Features
- Responsive webpage layout.
- Bootstrap-based grid system.
- Two-column content section.
- Styled header and footer.
- Full-width content section.
- CSS styling and transition effects.

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5

## How to Run
1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
